# shima M0 (pill, hover, displays, status menu) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the scaffold into the M0 island: invisible, flush with the notch when idle, it expands on an 80 ms hover dwell with a spring and concave "ear" corners, collapses 300 ms after the pointer leaves, never steals focus, handles built-in/notchless/no built-in displays, and has a status menu with Quit and Launch at login.

**Architecture:** All decisions live in `ShimaCore` as pure, tested values: display selection, layout geometry, the island path, and a hover state machine. A `HoverController` drives the machine through an injectable `Scheduler`, so tests never use real timers. `Shima` is glue. One persistent `NSPanel` holds a tracking view (an `NSTrackingArea` with `.activeAlways`) and an `NSHostingView` that draws an animatable `IslandShape`. The controller emits effects (`growPanel`, `animateExpand`, `animateCollapse`, `shrinkPanel`, ...), and the glue carries them out. The panel frame changes only at expand start and after collapse ends.

**Tech Stack:** Swift 6.1 (language mode 6), SwiftPM, AppKit + SwiftUI (macOS 14+), Observation, ServiceManagement, os.Logger, Swift Testing. No third-party packages.

**Spec:** `docs/2026-11-20-notch-design.md`. Authoritative for this plan: section 5.2 (M0 acceptance criteria 1-11), 6.4, 6.5, 6.6, 6.7 and section 7. Visual reference: `mockup/index.html` (read only, never modify).

## Review Focus

1. **Screen change while expanded or mid-animation** (lid closed during hover, monitor plugged in during collapse). The island must snap to collapsed on the new notch, and a late collapse-completion callback from the old animation must not shrink or grow anything. Test: `resetDuringCollapseIgnoresLateCompletion` in Task 8.
2. **Pointer already inside when the tracking rect is rebuilt** (after grow, shrink or a display change). The tracking view re-samples the pointer and sends a synthetic `pointer(inside:)`. A duplicate must not start a second timer or restart the dwell. Tests: `duplicateInsideEventsKeepOneTimer` in Task 8, `duplicatePointerInsideIsIgnored` in Task 7.
3. **An interrupted collapse animation completes after a re-expand.** SwiftUI may call the old `withAnimation` completion after the new animation starts. It must not shrink the panel under an expanded island. Tests: `lateCollapseCompletionAfterReexpandIsIgnored` in Task 7, `reenterDuringCollapseReexpandsWithoutRegrow` in Task 8.
4. **Spring overshoot or degenerate metrics** (radius greater than half the height, ear greater than the height, negative values in transitional frames). The path must clamp and never produce garbage or crash. Tests: `overshootMetricsAreClamped`, `negativeMetricsGiveEmptyPath` in Task 6.
5. **Built-in display that is not the primary screen** (an external monitor is main and the laptop sits to the left at negative x). Frames must follow the built-in screen's own coordinates. Tests: `expandedFrameOnOffsetScreen` in Task 5, plus the existing `notchOnOffsetScreenUsesScreenTop`.

- [ ] **Step 2: Write `scripts/verify-focus.sh`**

```bash
#!/usr/bin/env bash
# Criterion 6: polls the frontmost app every 0.1 s for N seconds (default 15) while you hover the island.
# PASS if the frontmost app never changes and Shima is never frontmost.
set -euo pipefail
secs="${1:-15}"
front() { lsappinfo info -only name "$(lsappinfo front)" | sed 's/.*="\(.*\)"/\1/'; }
echo "click into the app that should keep focus (3 s)..."; sleep 3
start="$(front)"; changed=0
echo "frontmost at start: $start (hover the island now, for ${secs}s)"
end=$((SECONDS + secs))
while (( SECONDS < end )); do
  now="$(front)"
  if [[ "$now" != "$start" ]]; then echo "CHANGED -> $now"; changed=1; start="$now"; fi
  sleep 0.1
done
if (( changed == 0 )) && [[ "$start" != "Shima" ]]; then echo "PASS frontmost unchanged: $start"; else echo "FAIL"; exit 1; fi
```

### Task 6: Island path with concave top ears

`UnevenRoundedRectangle` cannot draw concave corners (6.6). This builds the path as a pure `CGPath`, so it can be tested. Task 9 wraps it in an animatable SwiftUI `Shape`.

**Files:**
- Create: `Sources/ShimaCore/IslandPath.swift`
- Test: `Tests/ShimaCoreTests/IslandPathTests.swift`

**Interfaces:**
- Consumes: `IslandShapeMetrics`, `IslandLayout.expanded` (Task 5).
- Produces: `public enum IslandPath { public static func make(in container: CGRect, metrics: IslandShapeMetrics) -> CGPath }`. It uses **y-down** coordinates (SwiftUI's): the top of the island is `container.minY`, horizontally centered on `container.midX`.

Algorithm (not determined by the tests alone, so spelled out):
```
w = max(0, m.width); h = max(0, m.height)
ear = min(max(0, m.earRadius), h)
r = min(max(0, m.bottomRadius), w / 2, max(0, h - ear))
L = container.midX - w/2;  T = container.minY
move(L - ear, T)
addArc(tangent1End: (L, T),       tangent2End: (L, T + ear),        radius: ear)  // concave left ear
addLine(L, T + h - r)
addArc(tangent1End: (L, T + h),   tangent2End: (L + r, T + h),      radius: r)
addLine(L + w - r, T + h)
addArc(tangent1End: (L + w, T + h), tangent2End: (L + w, T + h - r), radius: r)
addLine(L + w, T + ear)
addArc(tangent1End: (L + w, T),   tangent2End: (L + w + ear, T),    radius: ear)  // concave right ear
close()
```
The ear arc is tangent to the top edge and to the island's side, so its circle is centered at `(L - ear, T + ear)`. Area inside that circle is transparent, and the corner between the arc and `(L, T)` is filled. This matches the mockup's `radial-gradient(100% 100% at 0 100%, transparent 97%, …)`.

```swift
public enum HoverPhase: Equatable, Sendable { case collapsed, dwelling, expanded, leaving, collapsing }
public enum HoverTimer: Equatable, Sendable { case dwell, leave }
public enum HoverInput: Equatable, Sendable {
    case pointer(inside: Bool), dwellElapsed, leaveElapsed, collapseFinished(generation: Int), reset
}
public enum HoverEffect: Equatable, Sendable {
    case startTimer(HoverTimer), cancelTimer
    case growPanel, shrinkPanel, setHotRegion(HotRegion)
    case animateExpand, animateCollapse(generation: Int), snapCollapsed
}
public struct HoverMachine: Sendable {
    public private(set) var phase: HoverPhase   // starts .collapsed
    public init()
    public mutating func handle(_ input: HoverInput) -> [HoverEffect]
}
```
Private state: `pointerInside: Bool` (false), `panelLarge: Bool` (false), `generation: Int` (0).

**Transition table** (the spec for the implementation; any input not listed returns `[]` and changes nothing).

`pointer(inside:)` first compares against `pointerInside`. An equal value returns `[]` (dedupe). Otherwise it stores the new value, then:

| phase | input | new phase | effects (in order) |
|---|---|---|---|
| collapsed | pointer(inside: true) | dwelling | `startTimer(.dwell)` |
| collapsing | pointer(inside: true) | dwelling | `startTimer(.dwell)` |
| dwelling | pointer(inside: false) | `panelLarge ? collapsing : collapsed` | `cancelTimer` |
| dwelling | dwellElapsed | expanded | `growPanel` (only if `!panelLarge`), `setHotRegion(.expanded)`, `animateExpand`; set `panelLarge = true` |
| expanded | pointer(inside: false) | leaving | `startTimer(.leave)` |
| leaving | pointer(inside: true) | expanded | `cancelTimer` |
| leaving | leaveElapsed | collapsing | `generation += 1`; `setHotRegion(.idle)`, `animateCollapse(generation:)` |
| collapsing | collapseFinished(g == generation) | collapsed | `shrinkPanel`; `panelLarge = false` |
| dwelling | collapseFinished(g == generation), `panelLarge` | dwelling | `shrinkPanel`; `panelLarge = false` |
| any | reset | collapsed | `generation += 1`; `cancelTimer`, `snapCollapsed`, `setHotRegion(.idle)`, then `shrinkPanel` if `panelLarge`; `panelLarge = false`, `pointerInside = false` |

**Interfaces:**

- Produces:
```swift
@MainActor public protocol ScheduledTask: AnyObject { func cancel() }
@MainActor public protocol Scheduler: AnyObject {
    func schedule(after delay: Duration, _ action: @escaping @MainActor () -> Void) -> any ScheduledTask
}
public struct HoverTiming: Equatable, Sendable {
    public var dwell: Duration; public var leaveDebounce: Duration
    public static let standard = HoverTiming(dwell: .milliseconds(80), leaveDebounce: .milliseconds(300))
}
@MainActor public final class HoverController {
    public init(scheduler: any Scheduler, timing: HoverTiming = .standard, perform: @escaping @MainActor (HoverEffect) -> Void)
    public var phase: HoverPhase { get }
    public var hasPendingTimer: Bool { get }
    public var onPhaseChange: (@MainActor (_ from: HoverPhase, _ to: HoverPhase) -> Void)?
    public func pointer(inside: Bool)
    public func collapseFinished(generation: Int)
    public func reset()
}
```
The controller keeps at most one pending task. It consumes `.startTimer` (cancel the old task, then schedule `dwell`/`leaveDebounce` that feeds `.dwellElapsed`/`.leaveElapsed`) and `.cancelTimer` (cancel and nil it). It passes every other effect to `perform`, in order, and calls `onPhaseChange` when the phase changes. When a task fires, it clears the pending reference before feeding the input.
- `DispatchScheduler: Scheduler` (in Shima) wraps `Task { @MainActor in try? await Task.sleep(for: delay); guard !Task.isCancelled else { return }; action() }` in a `ScheduledTask` whose `cancel()` cancels the Task. Nothing repeats.

`@MainActor final class ManualScheduler: Scheduler`. Fields: `now: Duration = .zero` and an array of entries `(due: Duration, seq: Int, action, task: ManualTask)`, where `ManualTask.cancelled` marks an entry as dead. Members: `var pendingCount: Int` (entries not cancelled), and `func advance(by d: Duration)`, which repeatedly pops the earliest live entry with `due <= now + d` (ties by `seq`), sets `now = due`, runs it, and finally sets `now` to the target.

### Task 12: Idle cost check script

Criterion 10, as a repeatable script.

**Files:**
- Create: `scripts/verify-idle.sh`

**Interfaces:**
- Consumes: a running `Shima` process.

- [ ] **Step 1: Write `scripts/verify-idle.sh`**

```bash
#!/usr/bin/env bash
# Criterion 10: keep the pointer away from the notch for the whole run.
set -euo pipefail
cd "$(dirname "$0")/.."
fail=0
echo "static check: no timers or event monitors in app code"
if grep -rnE 'addGlobalMonitorForEvents|addLocalMonitorForEvents|scheduledTimer|(^|[^A-Za-z])Timer[(.]|CVDisplayLink|repeatForever' Sources/Shima Sources/ShimaCore; then
  echo "FAIL static check"; fail=1; else echo "ok"; fi
pid="$(pgrep -x Shima)" || { echo "Shima is not running"; exit 2; }
secs() { ps -o time= -p "$pid" | awk -F'[:.]' '{ print ($1*60 + $2) + ("0." $3) }'; }
t0="$(secs)"; echo "pid $pid, waiting 60 s; keep the pointer away from the notch"
sleep 60
t1="$(secs)"
cpu="$(awk -v a="$t0" -v b="$t1" 'BEGIN { printf "%.3f", b - a }')"
rss_kb="$(ps -o rss= -p "$pid" | tr -d ' ')"
echo "cpu seconds used in 60 s: $cpu (pass <= 0.030, i.e. 0.0% average)"
awk -v c="$cpu" 'BEGIN { exit !(c <= 0.030) }' || { echo "FAIL cpu"; fail=1; }
echo "rss: $((rss_kb / 1024)) MB (pass < 60)"
(( rss_kb < 61440 )) || { echo "FAIL rss"; fail=1; }
top -l 2 -s 3 -pid "$pid" -stats pid,cpu,idlew,threads | tail -1 | sed 's/^/top (pid cpu idlewakeups threads): /'
out="$(mktemp -t shima-sample)"; sample "$pid" 3 -file "$out" >/dev/null 2>&1
if grep -q '__CFRUNLOOP_IS_CALLING_OUT_TO_A_TIMER_CALLBACK_FUNCTION__' "$out"; then echo "FAIL sample shows a run loop timer firing ($out)"; fail=1
else echo "sample: no timer callbacks; main thread: $(grep -m1 -oE 'mach_msg2_trap|mach_msg_trap' "$out" || echo '?')"; fi
(( fail == 0 )) && echo "PASS idle" || { echo "FAIL idle"; exit 1; }
```
Then `chmod +x scripts/verify-idle.sh`.
