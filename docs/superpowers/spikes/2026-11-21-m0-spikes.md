# M0 spike notes

## Spike 1: panel level, Spaces, fullscreen, transparent hit testing

Date: 2026-11-21. macOS 26.6.2, Swift 6.4.2, built-in display 1470x956 with a 179x32 notch.

### Level, Spaces and fullscreen (level `.statusBar`, collection behavior `[.canJoinAllSpaces, .stationary, .fullScreenAuxiliary, .ignoresCycle]`)

| Check | Result | Evidence |
|---|---|---|
| Pill visible on Space 1 | yes | screenshots |
| Pill visible on another (empty) Space | yes | user screenshot |
| Pill stays still while swiping between Spaces | not checked | the user did not test the swipe itself |
| Fullscreen Safari, menu bar hidden | yes, pill sits in the black notch band | user screenshot |
| Fullscreen Safari, menu bar slid down | yes, pill stays visible and flush with the notch | user screenshot |
| Fullscreen Terminal | not checked separately | Safari passed with the same level |
| Mission Control (F3) | no tile, no glitch | user report |

`islandLevel = .statusBar`. No higher level was needed, so `mainMenu3`, `popUpMenu` and `screenSaver` were not tried.
The flush idle pill sits over the physical notch, where the display has no pixels, so it is not visible to the eye (screenshots capture it, the screen does not show it). This is the wanted "invisible when idle" behavior.

### Transparent pixels (300x60 test panel: left half alpha 0, right half alpha 0.01)

Synthetic mouse events (CGEvent) were posted over each half and the panel's log was counted.

| Check | Result |
|---|---|
| Hover over the alpha 0 half | `enter`/`moved` received (6 moves at x<150) |
| Hover over the alpha 0.01 half | `moved` received (6 moves at x>=150) |
| Click on the alpha 0 half | **passed through**, no `mouseDown` on the panel |
| Click on the alpha 0.01 half | received (`mouseDown x=225`) |
| Visibility of 0.01 | not needed |

`hitOpacity = 0`. A fully transparent hot zone and hover margin receive tracking events, and clicks fall through to what is underneath (this is what criterion 7 wants). Clicks were tested once per half; Task 9 rechecks that the margin does not swallow menu bar clicks.
